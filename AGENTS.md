# AGENTS.md

notes for coding agents (claude code, codex, etc.) working on this repo. read README.md first for the hardware, the
bios settings and the install steps. this file covers how the repo is put together and the rules for changing it.

## what this is

an opencore 1.0.8 (RELEASE build) EFI for zeb's hp elitebook 850 g8 (i5-1145G7 tiger lake, iris xe), targeting
macos 26 tahoe. `EFI/` is the built output that gets copied to the usb or the laptop's efi partition. `src/` holds
everything it is built from.

## layout

| path | what |
| --- | --- |
| `EFI/OC/config.plist` | the config. generated by `src/make_efi.py`, don't hand-edit without updating the script too |
| `EFI/OC/ACPI/*.aml` | compiled from `src/SSDT-*.dsl` |
| `EFI/OC/Kexts/` | release kexts, plus two local patches (see below) |
| `src/make_efi.py` | builds `EFI/` and config.plist from extracted release zips |
| `src/install-tahoe.sh` | offline installer script that sits on the usb's exFAT INSTALL partition |
| `src/voodooi2c/` | pointing stick patch for VoodooI2C 2.9.1 and the script that builds it on the mac (command line tools, no xcode) |
| `assets/banner.png` | readme banner |

## building

`make_efi.py` takes two args: a work dir and the output dir.

```sh
python3 -I src/make_efi.py <work> <repo>
<work>/x/OpenCore-1.0.8-RELEASE/Utilities/ocvalidate/ocvalidate.linux <repo>/EFI/OC/config.plist
```

the work dir is expected to contain:

- `x/` with each release zip extracted under its own folder name, matching the paths in the `kexts` list
  (e.g. `x/Lilu-1.7.2-RELEASE/Lilu.kext`), plus `x/OpenCore-1.0.8-RELEASE/`, `x/SimpleHDA-Tahoe-v1.0.1-RELEASE/`, `x/master/OcBinaryData-master/` and `x/UTBMap/UTBMap.kext`
- `x/VoodooI2C-2.9.1-stick/` with the patched `VoodooI2C` and `VoodooI2CHID` binaries. run `src/voodooi2c/build.sh <work>`
  on the mac to make them (it clones pinned sources, applies the patch and builds the same bytes every time)
- `ssdt/` with the compiled `.aml` files

compile ssdts with `iasl` (acpica-tools). ocvalidate must report no issues before committing.

it wipes and rebuilds `EFI/` every run, so any change has to live in the script, not only in the output.

## local patches (re-apply when updating kexts)

- VoodooI2C 2.9.1 `Info.plist`: tiger lake i2c controller ids `0xa0e88086&0xFFFCFFFF 0x43e88086&0xFFFCFFFF` added to IOPCIMatch
- VoodooGPIO (VoodooI2C plugin): `INT34C5` added to IONameMatch. the 2.9.1 binary has no tiger lake code, so its binary is swapped
  for one built from VoodooGPIO master 44fc744 by `src/voodooi2c/build.sh`, and `-vi2c-force-polling` is gone. VoodooI2C and
  VoodooI2CHID are also built there, with `src/voodooi2c/pointing-stick.patch` (the pointing stick is touchpad report 0x18)
- VoodooI2C and VoodooI2CHID binaries: built from 2.9.1 plus `src/voodooi2c/pointing-stick.patch`. the pointing stick is not
  ps/2, it's mouse report 0x18 on the synaptics i2c touchpad (`18 <buttons> <dx> <dy>`). the patch parses generic desktop mouse
  collections with relative X/Y from the report descriptor and sends them to VoodooInput's trackpoint device
  (`kIOMessageVoodooTrackpointMessage`, so middle button scrolling works). make_efi.py drops the binaries into the release
  bundles, the release Info.plists and plugins stay. when moving to a newer VoodooI2C, re-apply the patch to it

- AppleALC 1.9.8: layout-id 71 (0x47). the binary is built by `src/applealc/build.sh` with layout 71's pin 0x17 path removed,
  and make_efi.py drops the 0x17 pin config verbs from the release Info.plist. pin 0x17 isn't wired on this laptop
- muteled (`src/muteled`) runs as a LaunchAgent on the mac and drives the mute leds through `alc-verbs`

## rules

- tahoe has no AppleHDA.kext. SimpleHDA injects it and must load after Lilu and AppleALC, with DisableLinkeditJettison on

- **WhateverXe replaces WhateverGreen. never add WhateverGreen**, the two must not load together. WhateverXe also needs
  AMFIPass 1.4.1 Mod (b00t0x's fork, not upstream), `-allow3d -disablegfxfirmware`, csr-active-config `03080000` and
  SecureBootModel `Disabled`
- keep `LapicKernelPanic` on, hp needs it
- keep IntelBTPatcher disabled: it hangs boot on tahoe 26.7.2 right after the hid drivers start. bluetooth works without it
- WhateverXe is the 91270 fork build of 0.7.0 with the 6 L3 bank fix, until upstream issue 24 is fixed. 0.6.1 does not work on 26.7.2
- keep the PlatformInfo serial, MLB, ROM and SystemUUID stable. the uuid is pinned in the script on purpose, regenerating it
  changes the mac's identity
- this is the public copy: PlatformInfo (serial, MLB, ROM, SystemUUID) holds opencore's sample placeholders. the real values
  live only in zeb's private repo
- never commit `SysReport/`, opencore logs or acpi dumps from the laptop. the MSDM table contains zeb's windows license key.
  `.gitignore` already covers SysReport, `opencore-*.txt`, `.pkg` and `.dmg`
- don't commit `com.apple.recovery.boot/` or the InstallAssistant.pkg, they come from apple
- bios video memory (dvmt) is 128 MB on purpose, 512 MB broke boot ("No slide values are usable")
- docs and comments are lowercase. never use middle dots or bullet dots as separators
- commit as `clawd <clawd@neptunethefox.dev>`. don't force push

## acpi paths on this machine

`_SB.PC00` root. `LPCB.EC0` (embedded controller), `GFX0` (igpu), `I2C0.TPD0` (SYNA30BE trackpad), `I2C1.TPL0`
(ELAN2513 touchscreen), `XHCI`, `TXHC` (thunderbolt xhci). cpus are `_SB.PR00`.. as Processor objects. AWAC disable uses `STAS`.
gpio controller `_HID` is `INT34C5`.
